# Shadow Strike — Neon Arena

A complete, mobile-friendly arcade shooter built with HTML, CSS and JavaScript. No libraries, accounts, or build tools required.

## Play locally
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Create a GitHub repository (for example, `shadow-strike`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a minute or two. GitHub will show your public game URL in the Pages section.

Anyone with that URL can play on desktop or mobile. The game is a browser game, not an installable Play Store APK.
